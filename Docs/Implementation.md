# TransitIQ Prototype Implementation

## Demonstrated Prototype

The current prototype is a browser-based dashboard built around a single HTML file and browser-loaded libraries.

### Main UI technology

- React 18
- ReactDOM 18
- Recharts
- Lucide React
- Leaflet

### Demonstrated modules

- Dashboard
- Live Fleet
- AI Detections
- City Map
- Road Health
- Smart Routes
- Analytics
- Alerts
- Resolution Center
- Settings

## Demonstration Data

The prototype uses simulated/sample values for buses, routes, detections, locations, issue counts and operational metrics.

The AI Detection screen presents a simulated bounding-box detection workflow. A production system can replace this layer with a trained edge model.

## Demonstration Controls

The prototype includes simulation/demo controls that allow the interface to show the monitoring and response workflow without a live fleet or backend.
