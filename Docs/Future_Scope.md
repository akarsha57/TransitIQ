# TransitIQ Future Scope

The following components can extend the prototype into a deployable city-scale system:

1. Real-time bus GPS and telemetry.
2. Bus-mounted camera integration.
3. Trained road-condition object-detection model.
4. Edge inference on vehicle hardware.
5. Backend APIs and authentication.
6. Geospatial database.
7. Real-time messaging/event streaming.
8. Maintenance-team assignment and status updates.
9. Historical road-health and route-risk analytics.
10. Model retraining using locally collected road imagery.
11. Authority dashboards and role-based access.
12. Cloud/edge deployment and monitoring.

These are future/production extensions and are intentionally separated from the current prototype scope.
